# Combat System

The combat system in Legends of the Ancient Realms provides an engaging and dynamic experience for players, with a focus on intuitive controls and visually appealing effects.

## Basic Attack

Each hero has a basic attack that serves as the primary combat mechanic:

- **Auto-targeting**: Basic attacks automatically target the nearest enemy within range
- **Hero-specific effects**: Each hero has a unique basic attack visual effect
- **Cooldown**: Basic attacks have a cooldown based on the hero's attack speed
- **Keyboard shortcut**: Press 'A' to trigger basic attack

## Skill Layout

Skills are arranged in a circular pattern inspired by Diablo Immortal:

- **Central Basic Attack**: The main attack button is positioned in the center
- **Surrounding Skills**: Hero-specific skills are arranged in a circle around the basic attack
- **Visual Indicators**: Each skill has a unique color and visual style based on the hero type
- **Cooldown Display**: Skills show a visual cooldown indicator when on cooldown

## Hero-Specific Skills

Each hero has four unique skills that complement their playstyle:

### Axe (Mogul Khan)
- Red-themed skills focused on physical damage and taunting enemies
- Skills include Berserker's Call, Battle Hunger, Counter Helix, and Culling Blade

### Crystal Maiden (Rylai)
- Blue-themed skills focused on ice magic and crowd control
- Skills include Crystal Nova, Frostbite, Brilliance Aura, and Freezing Field

### Lich (Kel'Thuzad)
- Dark blue-themed skills focused on frost damage and debuffs
- Skills include Frost Nova, Frost Armor, Dark Ritual, and Chain Frost

### Storm Spirit (Raijin Thunderkeg)
- Green-themed skills focused on lightning and mobility
- Skills include Static Remnant, Electric Vortex, Overload, and Ball Lightning

## Combat Effects

The combat system includes various visual effects to enhance the gameplay experience:

- **Projectiles**: Visible projectiles for ranged attacks and skills
- **Hit Effects**: Visual effects when attacks connect with targets
- **Damage Numbers**: Floating numbers showing damage dealt
- **Death Effects**: Special effects when enemies are defeated

## Mobile Controls

The game provides intuitive controls for mobile devices:

- **Joystick Movement**: A virtual joystick on the left side of the screen for movement
- **Skill Buttons**: Large, easy-to-tap buttons for skills
- **Auto-targeting**: Simplified targeting system for mobile play

## Wings Effect

When the hero is flying, wings appear behind them:

- **Animated Wings**: Wings animate with a flapping motion
- **Height Indication**: Wing animation changes based on ascent/descent
- **Visual Feedback**: Provides clear visual feedback for the flight state
